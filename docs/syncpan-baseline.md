# SyncPan / 盘同步 · 功能与体验基线

> 分析对象：`https://syncpan.top/`（Next.js 官网 + Tauri 桌面端产品文档）
> 分析时间：2026-11-14
> 分析方式：公开页面静态分析（HTML / CSS / Next.js 客户端 chunk）+ 官方使用文档交叉核对
> 分析边界：仅分析公开可访问内容，未登录进入产品内部，未进行二进制逆向、未抓取私有接口、未绕过任何授权校验

---

## 1. 产品定位

SyncPan 是一款**多网盘资源自动同步 / 转存工具**，桌面端（Windows / macOS / Linux）+ Docker（NAS 常驻），浏览器通过内置 HTTP 服务访问。核心价值是"一次打通 10 家网盘，把资源自动追更、批量搬运、集中管理"。

目标用户：追剧 / 追番的重度网盘用户、NAS 影音用户、需要批量整理分享链接的资源整理者。

宣称支持平台（10 家）：百度、夸克、阿里云盘、UC、123、115、光鸭、移动、天翼、迅雷。
各平台能力并不对等：自动追更仅支持百度 / 夸克 / 迅雷 / UC / 光鸭，其余平台在文件浏览、跨盘互传、批量转存中可用。

## 2. 核心功能清单

### 2.1 核心功能（侧栏第一组）

| 模块 | 关键能力 | 关键交互 |
|---|---|---|
| 自动追更 | 监控分享链接增量转存；Cron（周期 / 间隔 / 自定义 / 按更新时间滚动）；递归展开最深 15 层；glob / 正则 / 包含 / 排除过滤；风控（随机延迟、批次暂停、夜间降速、退避、阈值）；全局并发 + 同账号串行；聚合任务（一任务多子链接）；批量导入；TMDB 元数据；任务导入导出 JSON；按"平台+账号"记忆保存路径 | 新建任务弹窗 → 平台分组 Tab → 选保存路径 / 账号 / 多条分享链接 → 高级选项 → 保存；任务卡执行 / 暂停 / 日志 / 编辑 / 删除 |
| 追剧日历 | 电视剧 / 动漫 / 综艺 / 即将上线四分类；热度、更新周期、更新时间、播出状态、进度、源链接；一键复制 / 跳转观看；本地私有条目；已完结沉底；列排序 | 分类 Tab + 平台筛选 → 卡片/列表 → 点海报或"跟剧"创建追更 |
| 文件浏览 | 目录浏览 + 面包屑；重命名 / 删除 / 移动 / 复制 / 新建 / 分享；视频流播放、图片灯箱、文本阅读；上传下载；虚拟滚动 + 大目录分页；10 平台切换 | 顶部账号/平台切换器 → 工具栏（上传、新建、刷新、视图）→ 列表多选 → 批量操作条 |
| 跨盘互传 | 一源多目标；秒传探测优先 + 下载直链/官网上传兜底；Range 断点续传；任务持久化（暂停/恢复/取消/重试）；同名策略（跳过/覆盖/重命名）；1~16 并发 + 全局限速；逐条失败原因 | 选源文件 → 勾选目标账号/目录 → 冲突策略 → 创建任务 → 任务列表看进度 |
| 资源搜索 | PanSou 盘搜；边搜边出；自动剔除失效；平台筛选；复制链接；一键转存并分享；结果一键追更 | 搜索框输入 → 平台 chip 筛选 → 结果卡操作（复制/转存/追更） |
| 发现页 | 豆瓣榜单（热榜/口碑/新片/即将上映/冷门佳片）+ 热门资源（热播/新片/好评）；海报墙；点海报即搜 | 榜单 Tab → 海报网格 → 点击跳搜索 |
| 链接监控 | 订阅自建分享或任意网盘链接；定时巡检失效；失效推送；连续多次无法检测也提醒；与追更巡检独立开关 | 新增监控 → 选平台/链接/周期 → 运行记录 & 状态筛选 |

### 2.2 批量工具（侧栏第二组，8 个）

| 工具 | 能力 |
|---|---|
| 批量转存 | 批量解析分享链接 → 自动转存；进度追踪 / 失败重试；多账户分发；独立风控 |
| 批量分享 | 批量创建分享；有效期（1天/7天/永久）；提取码自定义；结果多选复制 |
| 批量重命名 | 正则替换 / 文本替换 / 序号 / 前后缀 / 改扩展名 |
| 链接转换 | 同平台分享链接互转，支持批量 |
| 广告清理 | 关键词 / glob / 正则匹配广告文件，批量删除，可暂停继续 |
| 广告插入 | 遍历或随机插入广告文件，多账户并行，普通/极速模式 |
| 目录树生成 | 递归导出网盘目录结构，树形/列表双模式，导出 txt |
| 我的分享 | 批量拉取分享列表（页数/天数/日期区间）；缓存；CSV 导出；批量取消 |

### 2.3 支撑能力

- 账号管理：多账号卡片/列表、拖拽排序、Cookie 校验与续期、10 平台扫码 / Device Code / OAuth / Cookie 粘贴、VIP 状态与到期倒计时。
- 通知推送：Bark、Server酱、钉钉、飞书、Telegram、PushPlus、企业微信（机器人 / 应用）、测试公众号、自定义 Webhook，共 10 通道并行。
- 内网穿透：内置 HTTP 服务（默认 9800）、通用 RPC、SSE 事件流（15s 心跳）、图片 / 缩略图代理、简易管理面板。
- 数据安全：Cookie / Token AES-256-GCM 加密，PBKDF2-HMAC-SHA256（10 万轮）派生密钥。
- 增值：VIP / SVIP（追剧日历、链接监控、内网穿透、QQ/微信通知、AI 智能体）。

## 4. 主要交互流程

### 4.1 首次使用

1. 启动应用 → 注册 / 登录（独立账号体系，卡密激活会员）。
2. 进入主界面 → 左侧栏「账号管理」→ 选择平台扫码 / OAuth / 粘贴 Cookie。
3. 校验 Cookie → 显示 VIP 状态与到期时间。
4. 进入「自动追更」→ 新建任务（名称、分类、更新时间、截止日期、执行频率、平台分组、保存路径、账号、分享链接、高级过滤）。
5. 保存 → 任务进入调度队列 → 卡片显示状态与已同步数量。
6. 命中新文件 → 自动转存 → 通知渠道推送。

### 4.2 资源发现到入库

搜索关键词 / 浏览发现页 → 结果卡「转存」或「追更」→ 选目标账号与目录 → 创建任务 → 任务中心查看进度 → 完成后在文件浏览中播放/整理。

### 4.3 批量整理

进入批量工具 → 选工具 → 粘贴多条链接 / 选择目录 → 配置并发、延迟、命名规则 → 执行 → 结果表逐条状态 → 失败重试 / 导出。

### 4.4 跨盘搬运

文件浏览选文件 → 跨盘互传 → 选目标账号与目录（可多选）→ 冲突策略 → 创建任务 → 任务列表暂停/恢复/重试。

## 7. 局限与未知

1. **未进入登录后产品**：任务卡、批量工具面板等细节来自官网 mockup 与文档描述，非真实运行时截图。
2. **未做运行时抓包**：无法确认其 API 协议、加密方式、桌面端 IPC；本次不涉及。
3. **平台能力不等价**：自动追更仅 5 家平台，文档明确其余平台不支持；复刻时不能按"10 家全支持"宣传。
4. **会员体系未验证**：定价页存在 VIP/SVIP 区分，但本次不实现付费能力。
5. **UI 像素级细节**：mockup 为营销用简化界面，真实应用可能存在额外控件；本次对齐的是信息架构、交互范式与视觉语言，不是像素级复刻。
